# Fewer cards, more clicks — Australian public libraries (FIT3179 DV2 draft)

Single-page visualisation built with Vega-Lite and published with GitHub Pages.

- `index.html` — page structure and narrative text
- `style.css` — layout (12-column grid), typography and colours
- `js/embed.js` — loads every chart into its box on the page
- `specs/` — one Vega-Lite spec per chart (`*.vg.json`)
- `data/` — CSV and TopoJSON files used by the specs

Status: draft. Figures come from the ALIA/NSLA Australian Public Libraries Statistical Reports; state populations are placeholders until ABS estimates are added.
